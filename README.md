# Static Uneven Distribution

## Deskripsi
Program ini merupakan simulasi distribusi beban secara statis menggunakan Python.

## Cara Kerja
Task dibagi ke beberapa processor menggunakan aturan berbasis indeks sehingga menghasilkan distribusi tidak merata.

## Output
Program menampilkan total beban tiap processor dan membandingkannya dengan nilai ideal.
